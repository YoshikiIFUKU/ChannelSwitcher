# Channel Switcher

1本のマイクの音を**2つの出力（仮想ケーブル）に同時に流し、出力ごとにミュートできる**ツールです。
入力チャンネルを2つ持つ音声認識ソフトに、「どちらのチャンネルで話しているか」を切り替えながら音を渡せます。

```
                              ┌→ CABLE-A Input ═(仮想ケーブル)═ CABLE-A Output → 音声認識の入力1
[実マイク] → ChannelSwitcher ─┤
                              └→ CABLE-B Input ═(仮想ケーブル)═ CABLE-B Output → 音声認識の入力2
```

ミュートした出力にも無音を送り続けるので、音声認識側の入力は途切れません。

## 動作環境

- Windows 10 / 11（.NET Framework 4.8 は標準で入っているので、追加のランタイムは不要）
- 仮想オーディオケーブル **2本**（各PCに1回だけインストール。管理者権限が必要）

## セットアップ（各PCで1回だけ）

1. **仮想ケーブルを2本用意する**
   - VB-Audio の [VB-CABLE A+B](https://vb-audio.com/Cable/) を使うと、`CABLE-A` と `CABLE-B` の2本が追加されます
     （無料版の VB-CABLE は1本だけなので、A+B が必要です）
   - インストーラを「管理者として実行」→ インストール後に再起動
   - ⚠️ 業務での利用条件は VB-Audio のライセンスを確認してください
2. **Windows の既定のデバイスを元に戻す**
   - インストール後、既定のスピーカーやマイクが CABLE に切り替わることがあります
   - 設定 → システム → サウンド で、出力・入力をいつものデバイスに戻してください
3. **音声認識ソフトの入力を設定する**
   - 入力1 → `CABLE-A Output`、入力2 → `CABLE-B Output`

## 使い方

1. `ChannelSwitcher.exe` を起動する
2. 「入力」に実際のマイク、「出力1」「出力2」に `CABLE-A Input` / `CABLE-B Input` を選ぶ
   （名前に CABLE を含むデバイスが自動で割り当てられます）
3. 「開始」を押す（話すとメーターが動きます）
4. ボタンでON／ミュートを切り替える

| 操作 | ショートカット | 動作 |
|---|---|---|
| 出力1ボタン | Ctrl+Alt+1 | 出力1 の ON／ミュートを切り替え |
| 出力2ボタン | Ctrl+Alt+2 | 出力2 の ON／ミュートを切り替え |
| 両方ON | Ctrl+Alt+3 | 両方を ON にする |

- ショートカットは音声認識ソフトを操作中（別ウィンドウが前面）でも効きます
- 切り替えは即時で、ノイズが出ないよう 20ms かけて音量を切り替えます
- 選んだデバイス・ミュート状態は次回起動時に復元されます（`%APPDATA%\ChannelSwitcher\settings.txt`）

## 確認のしかた

- サウンドの詳細設定（`mmsys.cpl`）→「録音」タブで、話すと `CABLE-A Output` / `CABLE-B Output` の緑のバーが動きます
- 仮想ケーブルに流した音はスピーカーからは鳴りません（正常です）

## 注意

- 出力にスピーカーを選ぶとハウリングすることがあります（確認ダイアログが出ます）
- 遅延はおおよそ 50〜100ms です
- マイクを抜き差ししたときは「停止」→「デバイス再読込」→「開始」してください

## ビルド

SDK は不要です。Windows 標準の C# コンパイラでビルドします。

```bat
build.bat
```

`dist\ChannelSwitcher.exe` ができます。配布はこの exe 1ファイルだけでOKです。
