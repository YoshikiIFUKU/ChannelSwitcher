# Channel Switcher

マイクの音を「左だけ」「右だけ」「両方」に振り分けて、仮想マイクとして音声認識ソフトに渡すツールです。
2チャンネル分岐アダプターの片側にマイクを挿し替える作業を、ボタン1つで置き換えます。

```
[実マイク] → [ChannelSwitcher.exe] → [CABLE Input]
                                          ↓（VB-CABLE 内部でつながっている）
                  [音声認識ソフト] ← [CABLE Output（仮想マイク）]
```

## 動作環境

- Windows 10 / 11（.NET Framework 4.8 は標準で入っているので、追加のランタイムは不要）
- VB-Audio Virtual Cable（各PCに1回だけインストール。管理者権限が必要）

## セットアップ（各PCで1回だけ）

1. **VB-CABLE をインストールする**
   - https://vb-audio.com/Cable/ から入手し、`VBCABLE_Setup_x64.exe` を「管理者として実行」→ インストール後に再起動
   - ⚠️ 業務での利用条件は VB-Audio のライセンスを確認してください
2. **CABLE Output をステレオにする**
   - サウンド設定 → 「サウンドの詳細設定」→「録音」タブ → `CABLE Output` → プロパティ →「詳細」
   - 既定の形式を **2 チャンネル、16 ビット、48000 Hz** にする
3. **音声認識ソフトの入力デバイスを `CABLE Output (VB-Audio Virtual Cable)` にする**
   - Windows の「既定のマイク」は変えなくてOKです（ソフト側で選べない場合だけ既定にしてください）

## 使い方

1. `ChannelSwitcher.exe` を起動する
2. 「入力」に実際のマイク、「出力」に `CABLE Input` を選ぶ（CABLE Input は自動で選ばれます）
3. 「開始」を押す
4. ボタンで切り替える

| ボタン | ショートカット | 出力 |
|---|---|---|
| 左のみ | Ctrl+Alt+1 | L = マイク、R = 無音 |
| 両方 | Ctrl+Alt+2 | L = R = マイク |
| 右のみ | Ctrl+Alt+3 | L = 無音、R = マイク |

- ショートカットは音声認識ソフトを操作中（別ウィンドウが前面）でも効きます
- 切り替えは即時で、ノイズが出ないよう 20ms かけて音量を切り替えます
- 選んだデバイス・モードは次回起動時に復元されます（`%APPDATA%\ChannelSwitcher\settings.txt`）

## 注意

- 出力にスピーカーを選ぶとハウリングすることがあります（確認ダイアログが出ます）
- 遅延はおおよそ 50〜100ms です
- マイクを抜き差ししたときは「停止」→「デバイス再読込」→「開始」してください

## ビルド

SDK は不要です。Windows 標準の C# コンパイラでビルドします。

```bat
build.bat
```

`dist\ChannelSwitcher.exe` ができます。配布はこの exe 1ファイルだけでOKです。
